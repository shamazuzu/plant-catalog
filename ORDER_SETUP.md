# Настройка заказов и уведомлений

## 1. Применить SQL-миграции

В Supabase → SQL Editor выполнить по порядку:

1. `supabase/migrations/20261031000200_orders_and_checkout.sql`
2. `supabase/migrations/20261031000300_customer_cart.sql`

Фронтенд сам SQL не применяет.

## 2. Развернуть Edge Function

Из корня репозитория с установленным Supabase CLI:

```bash
supabase functions deploy order-notifications
```

Функция использует пользовательскую JWT-сессию, проверяет владельца заказа и только после этого читает его позиции через service role.

## 3. Добавить секреты уведомлений

В Supabase → Project Settings → Edge Functions → Secrets добавить:

- `RESEND_API_KEY` — API-ключ Resend;
- `ORDER_EMAIL_FROM` — подтверждённый адрес отправителя, например `Kind of Green <orders@your-domain.ru>`;
- `ORDER_ADMIN_EMAIL` — твой email для копии заказа;
- `TELEGRAM_BOT_TOKEN` — токен Telegram-бота;
- `TELEGRAM_CHAT_ID` — твой личный chat ID.

Для Telegram сначала открой диалог с ботом и нажми Start. Бот не может первым написать пользователю.

Для отправки писем через Resend домен отправителя нужно подтвердить в Resend. Если настроен только Telegram, email покупателю отправлен не будет — это будет отражено в ответе функции.

## 4. Проверить регистрацию

В Supabase → Authentication → URL Configuration проверь Site URL и Redirect URLs для домена сайта. Если включено подтверждение email, покупатель должен перейти по ссылке из письма, затем вернуться на сайт и войти. Гостевая корзина останется в том же браузере и объединится с корзиной аккаунта.

## 5. Проверка тестового заказа

1. Создать тестовый аккаунт с email и телефоном.
2. Добавить товар в корзину, изменить количество, удалить позицию.
3. Войти после подтверждения email и убедиться, что корзина сохранилась.
4. Оформить тестовый заказ.
5. Проверить письмо покупателя, Telegram и вкладку «Заказы» в админке.
6. Проверить изменение статуса и уменьшение остатка.

Пока не проверены SQL-миграции, Edge Function и секреты, реальные уведомления не гарантируются.
